## วิธีเล่น (60 วินาที)
- ลากกระทงและขยะที่ลอยมาลงถังให้ถูก: **ย่อยสลายได้ · รีไซเคิลได้ · ขยะทั่วไป** ดูป้ายใต้ของแต่ละชิ้นว่าทำจากอะไร (ปล่อยเหนือถังก็นับ ถังจะดูดของเข้าหา · บนคอมกด 1 2 3 ได้ · เล่นครั้งแรกมีมือสาธิตการลาก)
- แยกถูก +10 (คอมโบเพิ่มคะแนน) และแม่น้ำใสขึ้น 1% · แยกผิด −5 และแม่น้ำ −2% · หลุดลงทะเล แม่น้ำ −5%
- แม่น้ำเปลี่ยนสีตามความสะอาด: ใส → ขุ่น → เน่า ถ้าเหลือ 0% จบเกมทันที
- จุดลุ้น: กระทงทองคำ x3 · กระทงโฟมทาสี (ของหลอกตา ต้องทิ้งขยะทั่วไป) · คลื่นขยะวินาทีที่ 30 และ 50 (+100) · คอมโบ 8 = พระจันทร์เต็มดวง x2 · เรือเก็บขยะ · ตาข่ายดักขยะ
- จบเกม: โบนัสความสะอาดที่เหลือ × 5 และแม่นยำ 100% +200 · ตอบคำถามถูก +50/ข้อ

## ระบบเหมือนเกมเดือนตุลาคม
เลือกแผนก + ชื่อจากชีต Employees · คนละ 3 ครั้ง · แบบทดสอบก่อน/หลังเล่น + การ์ด "รู้ไหม?" · KPI ใน Google Sheet · Ranking Top 10
**ใหม่:** แท็บ Department Battle (คะแนนแผนก = คะแนนเฉลี่ย × อัตราการเข้าร่วม) และตัวแซงอันดับระหว่างเล่น

## ติดตั้ง
1. สร้าง repository ใหม่ชื่อ `krathong-clean-up` อัป `index.html`, `og-thumb.png`, `README.md` → Settings → Pages → main / (root)
2. Google Sheet: แนะนำทำสำเนาไฟล์ของเดือนตุลาคม (File → Make a copy จะได้แท็บ Employees และ Apps Script มาด้วย) แล้วลบแท็บ Ghost Net Rescue / Quiz / KPI
3. เปิด Extensions → Apps Script วางโค้ด `apps-script/Code.gs` ทับ → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone)
4. นำลิงก์ `/exec` ไปใส่ที่ `APPS_SCRIPT_URL` ใน index.html

ถ้ายังไม่ใส่ลิงก์ เกมเล่นได้ปกติ (นับสิทธิ์และอันดับเฉพาะในเครื่อง)
